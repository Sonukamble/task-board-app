# 🗂️ Task-board-app
A clean full-stack task board with smart next-action recommendations, built using FastAPI and React.

# ✨ Features
--✅ Add, complete, and delete tasks

--📊 Visual progress indicator

--🎯 Next Best Action (NBA) Engine to recommend the most relevant task

--👤 User override to manually choose the active focus task

--📝 Optional task details (description & helpful resource links)

--🎨 Clean, minimal, and user-friendly UI
